# HRM Prototype Base (Vite + React)

A premium, lightweight, and fast-to-prototype base for HRM (Human Resource Management) applications or any internal tool.

## Tech Stack
- **Vite** - Build Tool
- **React** - UI Library
- **React Router 6** - Navigation
- **Lucide React** - High-quality icons
- **Framer Motion** - Premium animations
- **Vanilla CSS** - Custom variables & utilities (No heavy frameworks)

## Project Structure
- `src/components`: Reusable UI elements (Sidebar, StatCard, etc.)
- `src/layouts`: Page shells (MainLayout)
- `src/pages`: Feature views (Dashboard)
- `src/styles`: Design system (variables.css & main.css)

## Key Features
- **Dark Mode Support**: Built-in system preference awareness.
- **Glassmorphism**: Elegant UI effects using native CSS.
- **Responsive Sidebar**: Navigation ready to use.
- **Modern Typography**: Using Inter font family.

## Getting Started
1. `npm install`
2. `npm run dev`

## Why this base?
- **Minimalist**: No complex boilerplate or abstraction.
- **Fast**: Vite ensures lightning fast HMR.
- **Premium**: Pre-configured with a modern design system.
